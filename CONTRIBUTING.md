# Contributing

Use Node 24.18+ and pnpm 11.24.0. Read AGENTS.md and the nearest package guide.
Run `pnpm format-check`, `pnpm lint`, `pnpm check`, `pnpm test`, `pnpm build`
and `pnpm knowledge:check` before proposing changes. Use synthetic fixtures and
include regression coverage. Keep generated artifacts and personal data untracked.
Use Conventional Commits and open reviewable pull requests; do not deploy as part
of a code review.
