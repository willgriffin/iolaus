# Job workspace-subject test matrix

Issue [#138](https://github.com/willgriffin/iolaus/issues/138) binds every
candidate-owned queued job to the verified workspace subject that created it.
The durable job argument is the canonical
`runtimeWorkspaceSubject: { tenantId, userId, profileId }` envelope. A worker
rechecks the active user, active membership with a role, and owned active
candidate profile immediately before it executes private work.
